(https://github.com/wm821457-alt/mckinney_william_FinalProject_FireworksSim.git)

## Description
Using Pygame I am going to create an interactive fireworks simulator that when you click on the anywhere on the screen it will create these multicolored firework explosion balls. Each individual explosion will create particles shooting outward like a real firework as well as fall/fade in real time. Accurate but cool looking. Can create as many as you want and control with keyboard commands as well. 

## Features
- Feature 1: Firework Intractable's
	- click anywhere on screen for firework EXPLOSIONS
    - pygame use at mouse click for complete control
- Feature 2: Random Colors
	- each explosion will pick from color list and each have different look
    - python random for multicolor
- Feature 3: Particle Movement
	- track multiple explosions all at once without issues interacting with others
    - all update independently through different classes outlined
- Feature 4: Keyboard Controls
    - C to clear and escape key. Classic but essential
