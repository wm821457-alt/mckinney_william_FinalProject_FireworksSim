## Description
Using Pygame similar to the last digital rain assignment I will display an interactive Firework Simulator. User's will be able to click anywhere on the screen and create different colored explosions that will shoot out and disappear after.  

## Features
- Feature 1: Keyboard Controls
	- press keys to change colors or clear up screen
- Feature 2: Random Colors
	- each explosion will pick from color list and each have different look
- Feature 3: Particle Movement
	- particles move outward from explosion and disappear like a real firework
